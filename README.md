# Backlash Journal · 网站状态

给 [backlashjournal.com](https://backlashjournal.com) 做的两项自动检查。放在公开仓库，是因为公开仓库的 GitHub Actions 分钟数不限量，不占私有仓库的免费额度。仓库里没有任何密钥。

- **掉线提醒**（`uptime.yml`）：每 30 分钟打开首页、中文首页、法规速查、站内搜索、网站地图、写稿后台，看是否返回 200 且内容对。失败会先等 60 秒重试一次，两次都失败这次运行才算失败。运行失败时 GitHub 会给仓库主人发邮件。
- **每周体检**（`lighthouse.yml`）：每周一用 Lighthouse 测首页、一篇文章、一个法规页，分别看性能、无障碍、最佳实践、SEO 四项得分。性能低于 60 分、其余三项低于 90 分就算失败（手机网速下的性能分波动大，门槛放低以免误报），每页测 3 次取中位数，GitHub 同样会发邮件。每次的分数写在运行页面的 Summary 里。

GitHub 会在仓库 60 天没有活动后停掉定时任务，所以掉线检查每月 1 号会往 `heartbeat.txt` 提交一次日期，保持仓库活跃。
